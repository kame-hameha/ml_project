Lernsituation KI-Sichtprüfstation · Doppelstunde 2

Aus einer Matrix wird ein Vektor (Flatten)

Matrix = eine Tabelle aus Zahlen mit Zeilen und Spalten.
Ein Bild ist eine Matrix: Jede Zahl ist ein Pixel. Hier: 5 Zeilen × 5 Spalten = 25 Zahlen.
Vektor = eine einzige Reihe von Zahlen.
Ein einfaches neuronales Netz kann nur Vektoren verarbeiten. Deshalb werden die Zeilen hintereinander gehängt.

1 = Strich (dunkel), 0 = Papier (hell). Klicken Sie auf ein Feld, um es zu ändern. Jede Zeile hat eine eigene Randfarbe.

Vorlage:
In Keras erledigt das layers.Flatten(). Es geht keine Zahl verloren – nur die Anordnung ändert sich. Fahren Sie mit der Maus über ein Feld: Orange markiert sind die Nachbarn darüber und darunter. Achten Sie darauf, wo diese Nachbarn im Vektor landen.
Arbeitsauftrag
  1. Wie viele Zahlen hat die Matrix, wie viele der Vektor?
  2. An welcher Stelle im Vektor steht die erste Zahl der dritten Zeile?
  3. Ein Bild hat 32 × 32 Pixel. Wie lang ist der Vektor nach dem Flatten?
  4. Zwei Pixel liegen im Bild direkt übereinander. Wie weit sind sie im Vektor voneinander entfernt? Was bedeutet das für das Netz?
