Lernsituation KI-Sichtprüfstation · Doppelstunde 7

Ist das Modell gut genug für die Fertigung? Konfusionsmatrix

Eine einzige Zahl wie „95 % Genauigkeit“ reicht in der Produktion nicht. Entscheidend ist, welche Fehler passieren. Ein fehlerhaftes Teil, das durchgelassen wird und zum Kunden gelangt, ist meist viel problematischer als ein gutes Teil, das unnötig aussortiert wird.

1 · Gut-/Schlecht-Prüfung mit Entscheidungsschwelle

Das Modell gibt für jedes Teil eine Wahrscheinlichkeit „fehlerhaft“ aus. Liegt sie über der Schwelle, wird das Teil ausgeschleust. Grün: gute Teile, rot: fehlerhafte Teile.

2 · Konfusionsmatrix für mehrere Klassen

Tragen Sie die Werte aus Ihrem Notebook ein (Zeile = tatsächliche Klasse, Spalte = Vorhersage).

Precision (Präzision): Von allen Teilen, die das Modell als Klasse X einsortiert, wie viele sind wirklich X?
Recall (Trefferquote): Von allen echten X, wie viele hat das Modell gefunden?
F1: harmonisches Mittel aus beiden. Accuracy: Anteil aller richtigen Entscheidungen.
Arbeitsauftrag
  1. Bei Schwelle 0,5: Wie viele fehlerhafte Teile pro Schicht werden durchgelassen und gelangen zum Kunden? Wie viele gute Teile werden unnötig aussortiert?
  2. Verschieben Sie die Schwelle. Wie verändern sich die beiden Fehlerarten – durchgelassene Fehler und unnötig aussortierte gute Teile – gegenläufig? Warum kann es sinnvoll sein, die Schwelle unter 0,5 zu legen?
  3. Stellen Sie den Fehleranteil auf 1 %. Ein Modell, das immer „i. O.“ sagt, hätte dann 99 % Accuracy. Warum ist es trotzdem unbrauchbar? Welche Kennzahl zeigt das?
  4. Tragen Sie die Konfusionsmatrix Ihres CNN aus Notebook 12 ein. Welche zwei Klassen werden am häufigsten verwechselt? Nennen Sie eine mögliche Ursache und eine Gegenmaßnahme bei der Datenaufnahme.
